# 看懂 · v0

鼠标 Agent 的最小切口。在终端里**划选任何看不懂的东西,按个快捷键,当场用大白话解释**——不用切窗口、不用复制到别的地方、不用稀里糊涂点"继续"。

复用你已经装好的 Claude Code,**不需要 API key**。

## 怎么用

### 快捷键(都在 `/`(?)键上,不同修饰键)

- **⌥?**(Option+/)→ 全局智能键
  - **划选了文字** → 解释那一段(术语/代码/报错;若是操作,还提示风险+该不该放行)
  - **没选中** → 读最近屏幕:末尾有 cc 权限请求 → 解释+**评估风险**+该不该同意;否则 → **总结最近发生了什么**
- **⌘⌥?**(Command+Option+/)→ 详细解释选中内容(用更聪明的模型)
- **⌘⇧?**(Command+Shift+/)→ 本周卡点小结(归纳你最近主要卡在哪几类)

浮窗几秒后出结果(加粗/分点/代码会渲染好;快查用 haiku 更快)。看完按 **Esc** 关掉(或 60 秒自动消失)。
45 秒没回会提示重试,不会一直转。

**流式输出**:详细解释 / 周小结 / 读屏总结这类长答案是**边生成边显示**(像打字一样逐段出现),不用干等全部。快查是一句话,直接出。
> 说明:每次调用前 ~8 秒是 cc 自己在加载(插件等),这段时间任何答案都出不来,是固定开销;流式让长答案在那之后能尽早开始显示。

### 看懂 cc 要执行的操作(同一个键)
cc 要跑命令、改文件、请求你批准时(屏幕上显示 `Bash command`、`Bash(...)`、`Waiting…` 等,
格式可能多种多样),**划选那段,按 ⌘⌥E**。它会告诉你:这操作在干嘛、有没有风险、该不该放行。
看完你再决定批准/拒绝。

**为什么只要一个 ⌘⌥E 就够**:判断"这是普通术语还是要执行的操作"交给 AI 本身,不靠死板的格式匹配。
所以不管 cc 的提示长什么样,你选中按 ⌘⌥E 都对:
- 选中是要执行的操作 → 额外提示风险 + 该不该放行
- 选中是术语/代码/报错 → 直接大白话解释(并说明"这不是操作,不用放行")

## 自动放行安全命令(少被打扰)

cc 每次要执行命令前,`auto-approve.py` 会先判断风险:
- **只看不改 + 常见安全操作**(`ls`/`cat`/`git status`/`grep`/`npm test`/`pytest`…)→ **自动放行**,不问你
- **高风险**(`rm -rf /`、`sudo`、`curl|sh`、`git push --force`…)→ **不拦,但停下来提醒你再决定**
- **其余**(改文件、装东西、`touch`、`mv`…)→ **照常问你**(这时选中按 ⌘⌥E 看懂它)

> 为什么高风险不直接拦死:实战里硬拦没用——cc 会自动换一种等效写法绕过,反而给你"被保护了"的错觉。
> 所以这里只**额外提醒风险 + 强制停下来问你**,把决定权留给你(看懂后再放行)。

安全设计:命令里只要有可能"夹带"危险的拼接(`;` `&&` `>` 等),一律不自动放行;
`ls && rm -rf ~` 这种不会因开头是 `ls` 就被放过,会走正常询问。

**透明可查**:每次自动放行/提醒都记在 `~/.config/kandong/logs/auto-approve.jsonl`,你能随时回看它替你做了什么决定。

**激活**:改了 cc 配置后需**重启 Claude Code**(退出再进)才生效。
**调整范围**:编辑 `auto-approve.py` 里的 `READONLY` / `SAFE_PROJECT` / `RISKY` 列表。
**关掉**:把 `~/.claude/settings.json` 里 `hooks` 那段删掉(或用备份 `settings.json.bak.*` 还原),重启 cc。

## 第一次启动要做的一件事(只做一次)

Hammerspoon 需要"辅助功能"权限才能模拟复制和监听快捷键:

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**
2. 找到 **Hammerspoon**,把开关打开(没有的话点 ➕ 把 `/Applications/Hammerspoon.app` 加进去)
3. 回到 Hammerspoon(菜单栏的锤子图标)→ 点 **Reload Config**

看到"看懂 v0 已就绪"的提示就成了。

## 改了代码怎么生效

逻辑都在 `kandong.lua`。改完后点菜单栏锤子图标 → **Reload Config** 即可,不用重装。

## 它记录了什么(你的数据飞轮)

每次解释,会往 `~/.config/kandong/logs/confusions.jsonl` 追加一行:时间、quick/deep、选中字数、前 100 字预览。
这是"数据飞轮"的原料。**这个日志只在用户本机,不上传。**

## 越用越懂你(个性化,全本地)

看懂会记住"你这个人"反复卡在哪、什么程度,讲解越来越贴你——这是云厂商不愿/不便做的护城河。两块都**纯本地、不上传、几乎零延迟**:

- **个人画像(台阶 1)**:每次 quick/deep 解释前,纯计算地数一下你最近卡点的类别(依赖/报错/git/权限/配置),拼一句"读者画像"塞进给 cc 的指令,让它按你的程度讲。数据越多越准;少于 5 条不画像(新用户行为同今天)。
- **个人词典(台阶 3)**:你 quick 问过的"词/命令"+ 当时听懂的解释,存到 `~/.config/kandong/personal_dict.json`。下次同一个词 **0ms 秒出、还用你上次听懂的说法**。
  - 注意:这是本地会**存解释结果**的地方(为了秒答)。仍然**只在本机、不上传**。不想要就删这个文件。

## 匿名使用心跳(算"留存"用)

为了知道"装了之后还有没有人在用"(留存),按快捷键时会发一个极克制的事件:
- **发的内容**:一串**随机匿名码**(本机生成、存在 `~/.config/kandong/anon_id`,跟用户是谁/设备无关)、事件名(`installed` / `used`)、日期、版本、系统。
- **绝不发**:任何选中内容、屏幕文字、文件名、路径。
- **频率**:装机发一次 `installed`;之后**每天首次使用**发一次 `used`(够算留存,不刷量)。
- **怎么关**(即时生效、不用重载):`touch ~/.config/kandong/telemetry.off`

**开启方法(给作者)**:去 [PostHog](https://posthog.com) 建个免费项目,把 **Project API Key** 填进 `kandong.lua` 顶部的 `POSTHOG_KEY`(EU 区项目改 `POSTHOG_HOST`)。
**没填 key 时,这段完全是 no-op,什么都不发**——所以默认空着、提交进仓库也安全。PostHog 直接出留存曲线,你不用自己维护数据库。

## 卸载

- 关掉看懂:删掉 `~/.hammerspoon/init.lua` 里那行,Reload。
- 不要 Hammerspoon 了:`brew uninstall --cask hammerspoon`

## 已知局限(v0)

- 终端里"悬停自动解释"做不了(终端没有网页那种结构),所以用"划选 + 快捷键"。
- 每次解释要等几秒(走的是 `claude -p`,会起一个 cc 进程)。以后接 API 可以更快。
- 解释质量取决于你选中的上下文够不够;选多一点效果更好。
